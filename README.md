## What I Learned

- All four heartbeats: In-session, Conditional, Scheduled, and Event-driven
- Spine (memory between runs)
- Maker-Checker pattern
- Human Gate
- Observability and cost awareness
- Proper secrets handling
- Improvement loops (Dreaming)

## Structure

Each project lives in its own folder (`loop1` to `loop12`) with its own `progress.md`, logs, and relevant files.

## Notes

These are practice projects built for learning purposes. Some loops were intentionally broken and fixed to understand failure modes and observability.
