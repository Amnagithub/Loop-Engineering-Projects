# Project 2 - Make the tests pass, then stop.

This project contains a `calculator.py` module with intentional bugs and a
`test_calculator.py` suite that currently fails.

We will use a conditional loop (`/goal`) to keep fixing the code until the
tests pass. The test command decides when to stop: once `pytest` (or the test
command) passes, the loop ends.

## Files

- `calculator.py` - the functions to fix
- `test_calculator.py` - the tests that must pass
- `progress.md` - notes on current progress
- `loop-log.md` - log of each loop iteration
