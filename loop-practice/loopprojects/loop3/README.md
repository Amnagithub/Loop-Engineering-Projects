# Loop 3 — Morning Brief with Memory (Spine)

The loop reads `progress.md` to pick up where the previous run left off, gathers
simple info (TODOs or recent commits), writes a short summary, and updates
`progress.md` so the next run has memory.

## Files

- `progress.md` — the persistent memory of the loop (read + updated each run).
- `loop-log.md` — a simple running log of each run.
